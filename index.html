AI-Powered Healthcare Insurance Risk Prediction System

A machine learning system designed to predict financial risk in healthcare insurance claims using logistic regression and advanced feature engineering.

The Problem

Healthcare insurance providers face escalating costs due to unpredictable claim patterns and shifting regulatory landscapes (SHIF/SHA in Kenya). Traditional actuarial methods fail to capture the complexity of individual risk profiles, resulting in poor premium pricing and exposure to catastrophic losses.

The Solution

I engineered a complete machine learning pipeline that ingests patient demographics, medical history, and claims data to predict individual risk scores. The system used Logistic Regression to achieve 93% classification accuracy, enabling data-driven underwriting decisions. The model was built with regulatory awareness—continuously adapting to evolving national insurance schemes to remain compliant and actuarially sound.

Technical Stack

Python Scikit-Learn SQL Pandas Machine Learning Data Pipelines
  • Data Engineering: Built secure, scalable ETL pipelines to ingest and validate financial and medical datasets.
  • Feature Engineering: Designed domain-specific risk features (hospitalization frequency, claim severity, comorbidity flags) with business logic alignment.
  • Model Training: Logistic Regression with cross-validation, achieving 93% ROC-AUC accuracy and robust generalization.
  • Regulatory Adaptability: Designed system to accommodate evolving insurance regulations (SHIF/SHA), demonstrating foresight for real-world deployment.

Case Study

Healthcare Management System

A full-stack data management platform designed to modernize healthcare record-keeping and operational workflows.

The Problem

Healthcare facilities operating on paper-based or fragmented digital systems face critical inefficiencies: patient records are siloed across departments, appointment scheduling is manual and error-prone, and there is no centralized mechanism to query, audit, or report on operational data. This results in delayed diagnoses, duplicated patient entries, and zero visibility into facility performance metrics.

The Solution

I designed and developed a fully functional, web-based Healthcare Management System that centralizes all patient and operational data behind a secure, role-based interface. The system enables healthcare workers to register patients, manage consultation records, schedule appointments, and generate on-demand reports — all from a single dashboard. Data integrity is enforced through a normalized relational database, while the Flask backend exposes clean routes for all CRUD operations, making the system extensible for cloud deployment.

Technical Stack

Python Flask SQL HTML / CSS Relational DB Design REST Architecture
  • Backend: Python + Flask — lightweight, scalable, production-ready web framework with modular route handling.
  • Data Layer: SQL with normalized schema design — enforcing referential integrity across patient, appointment, and clinical record tables.
  • Frontend: Semantic HTML5 + CSS3 — clean, responsive UI designed for clinical staff with minimal technical background.
  • Architecture: MVC pattern enabling straightforward feature extension, testability, and cloud-readiness for modern deployment.
