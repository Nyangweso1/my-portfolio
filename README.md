# Prudence Nyangweso — Portfolio

Personal portfolio website for **Prudence Moraa Nyangweso**, a Data Scientist and AI/ML Specialist focused on turning data into actionable intelligence.

## About

This portfolio presents Prudence's experience, technical skills, projects, certifications, and contact information.

Core areas include:

- Data science and machine learning
- Data analysis and business intelligence
- Python and SQL
- Power BI and Microsoft Fabric
- Financial and operational analytics

## Features

- Responsive single-page portfolio layout
- About, skills, projects, experience, certifications, and contact sections
- Mobile navigation
- Scroll animations and interactive UI elements
- Contact form with EmailJS support and email fallback
- CV access handled through an authorization request by email

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts
- EmailJS

## Run locally

No build tools are required. Open `index.html` in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
